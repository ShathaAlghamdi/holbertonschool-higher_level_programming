# JavaScript - DOM manipulation

Scripts that run in the browser and change the page without reloading it:
selecting elements, changing styles and classes, reacting to clicks,
creating elements and fetching data with the Fetch API.

| File | Description |
| ---- | ----------- |
| 0-script.js | Colors the header red with `document.querySelector` |
| 1-script.js | Colors the header red when `#red_header` is clicked |
| 2-script.js | Adds the class `red` to the header on click |
| 3-script.js | Toggles the header between the classes `red` and `green` |
| 4-script.js | Adds `<li>Item</li>` to `ul.my_list` on click |
| 5-script.js | Changes the header text to `New Header!!!` on click |
| 6-script.js | Fetches a Star Wars character name into `#character` |
| 7-script.js | Fetches all Star Wars movie titles into `ul#list_movies` |
| 8-script.js | Fetches "hello" in French into `#hello` (loaded from `<head>`) |
