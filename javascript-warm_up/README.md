# JavaScript - Warm up

Basic JavaScript scripting with Node.js: variables, constants, data types,
conditions, loops, functions, objects, arguments and modules.

| File | Description |
| ---- | ----------- |
| 0-javascript_is_amazing.js | Prints a constant |
| 1-multi_languages.js | Prints 3 lines |
| 2-arguments.js | Message depending on the number of arguments |
| 3-value_argument.js | Prints the first argument |
| 4-concat.js | Prints two arguments as "a is b" |
| 5-to_integer.js | Converts the first argument to an integer |
| 6-multi_languages_loop.js | Prints 3 lines using an array and a loop |
| 7-multi_c.js | Prints "C is fun" x times |
| 8-square.js | Prints a square of X |
| 9-add.js | Adds two integers with a function |
| 10-factorial.js | Recursive factorial |
| 11-second_biggest.js | Second biggest integer in the arguments |
| 12-object.js | Updates an object's value |
| 13-add.js | Exported add function |
